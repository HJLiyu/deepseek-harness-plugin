# 接入层与验证范围

连接配置保存在实际数据目录的 model-connections/，不属于源码和发布内容。每次修改服务地址、CLI 或默认模型保存为新连接；既有群继续引用原连接。API 对话、工具操作状态和最终结果在独立 SQLite 日志中保存。

API 请求不自动重试，拒绝访问和额度错误作为已知失败结算。工具执行前检查需求版本、群 epoch 和原投递绑定；每个工具调用编号只允许处理一次。已完成投递可恢复结果，未知投递必须核对原效果，不能直接重发。用户的原始消息仍由群聊存储保留；API 历史达到阈值后按完整需求块裁剪，不截断工具调用配对，也不为每条消息另调模型。

新增测试涵盖：

- 真实本机 HTTP 兼容服务：模型目录、多次 function call、文件写入、上下文复用、HTTP 401、写入后网络断开。
- 真实 Node 子进程：Codex app-server 与 Harness ACP 握手、会话创建／恢复、最终消息与阶段权限回执。
- 越界路径、junction、计划／复核禁写、过期需求、命令拒绝、输出上限和原生真人审批防重用。
- Windows 本机实装 Codex／Harness 模型目录和 Codex command/exec 沙箱只读探针；Harness 真实恢复及策略加载在发送推理前中断验证；另以短回复验证真实 Harness 推理及 Codex CLI 连续两轮上下文复用。

真实供应商付费推理不纳入默认测试。CLI、Harness 和桌面协议会随版本变化；不支持的能力应报告具体缺口，不自动切换成完整权限。公开 CI 与本机全套测试应在合并前通过。

API 写入路径在审批前后都规范化并检查链接。主机上其他可信进程仍可能并发改变文件系统；工具不是针对恶意本机管理员的隔离边界。完整项目命令由真人审阅精确参数后在原生沙箱执行；本插件不实现自制 shell 沙箱。
